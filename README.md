# 🍭 RusicApplication Monorepo

Welcome to the RusicApplication Turborepo!  
Everything you need for a modern, scalable, TypeScript-powered fullstack project.

---

## 🚀 Getting Started

```sh
npx create-turbo@latest
```

---

## 📦 Structure

```
├── apps
│   └── Rusic
├── packages
│   └── db
├── .vscode
├── .gitignore
├── pnpm-lock.yaml
├── turbo.json
└── README.md
```

---

## 🧩 What's Inside?

- **Apps**
  - `docs`: Next.js documentation app
  - `web`: Next.js web app

- **Packages**
  - `@repo/ui`: Shared React UI components
  - `@repo/eslint-config`: Shared ESLint config
  - `@repo/typescript-config`: Shared TypeScript config

---

## 🛠️ Tooling

- TypeScript for type safety
- ESLint for linting
- Prettier for formatting

---

## 🏗️ Build Everything

```sh
cd my-turborepo
pnpm build
```
